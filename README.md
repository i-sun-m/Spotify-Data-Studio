Spotify Data Analysis & Playlist Recommendation

A Python project for analyzing Spotify music data and generating playlists using track features and a scoring-based recommendation approach.

Overview

This project explores Spotify track data through data preprocessing, analysis, and visualization. It also includes a scoring system that evaluates tracks based on selected features and uses the results to generate a recommended playlist.

The project was developed as a practical exercise in Python, data analysis, and working with structured datasets.

Features

Spotify dataset exploration and analysis

Data preprocessing and cleaning

Analysis of track features

Statistical and descriptive analysis

Data visualization

Track scoring system

Playlist generation based on calculated scores

Interactive menu for accessing different parts of the project

How It Works

The project starts with an interactive menu that allows the user to select different operations.

The Spotify data is loaded and processed before being used for analysis. Various track characteristics can then be explored through statistical analysis and visualizations.

A scoring-based system is also used to evaluate tracks according to selected features. The calculated scores are then used to select tracks and generate a recommended playlist.
